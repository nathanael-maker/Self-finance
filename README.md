# 自金融 / Self-Finance

> 把金融从一个靠不可见性牟利的行业,改造成一个可读的行业。
> Make finance legible.

## 这是什么

一套开源的金融认知基础设施,由一场人与AI的长对话生长而来。它包含三层:

1. **地图(docs/)** —— 《金融产品全景地图》:以「错配」为第一性原理,把全部金融产品
   还原为六个原子(时间/风险/规模/流动性/空间/信息控制权),逐族判定:
   哪些真正解决错配、哪些是好原子套坏激励的退化态、哪些天生不解决任何错配。
   附「错配仪表盘」:评估系统性错配是否在拉大的四层指标体系。

2. **实测(research/)** —— 仪表盘的首批判例:
   - v0.1 美国1985–2023,股权与住房层:索取权层增速持续超过资源层约3个百分点/年,从未转负;
   - v0.2 JST宏观史数据库17国150年:金融曲棍球棒——1980年后从历史高位再加速,150年首见;
     错配发动机2005年后从私人部门换挡至主权资产负债表;
   - v0.3 FRED交叉验证:两套独立数据精确互证;影子化定量(美国过半私人信贷在银行体系外);
     2021–2024通胀对名义债权执行了一次减记,但净财富/GDP不降反升——
     错配第三次换乘,迁入抗通胀形态。
   - 核心叙事:索取权层逐一进化出对三把历史重置之刀(监管/违约/通胀)的抗性,
     错配持续向缓冲更薄、监督更少的形态迁徙。

3. **代码(code/)** —— 全部计算可复现。数据源全部开放(GitHub开放镜像/FRED/JST)。

## 总纲(不可妥协)

见 [CHARTER.md](CHARTER.md)。核心三条:**永不预测价格;永不推荐买卖;一切评价锚定当前价格。**
本项目只做一件事:降低看清真相的成本。

## 复现

```bash
pip install pandas matplotlib openpyxl
python code/mismatch.py      # v0.1: 需要datahub开放数据(脚本内注明仓库)
python code/jst_analysis.py  # v0.2: 需自行从 macrohistory.net 下载 JSTdatasetR6.xlsx(CC-BY-NC)
python code/crossval.py      # v0.3: 需从 FRED 下载 CRDQUSAPABIS/TCMDO/M2SL/TNWBSHNO 四个CSV
```

原始数据不随仓库分发(尊重各数据源许可),脚本内注明获取路径。
